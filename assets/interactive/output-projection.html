An executable mental model · C = 6 · 3 heads × 2 features

What does self.c_proj actually do?

Each output feature is a learned weighted sum of all six concatenated features. Watch one output accumulate contributions from all three heads.

Define once. Apply on every forward pass.

# __init__: allocates learnable weight (6, 6) and optional bias (6,)
self.c_proj = nn.Linear(cfg.n_embd, cfg.n_embd, bias=cfg.bias)
# forward: heads have already been concatenated into x
y = self.c_proj(x)  # x: (B, T, 6) → y: (B, T, 6)
# equivalent computation:
y = x @ self.c_proj.weight.T + self.c_proj.bias  # when bias=True

The same weights apply independently to every token and batch item. This layer mixes features within a token; it does not mix token positions.

Illustrative weights, not a trained model. Edit inputs below; click a matrix cell to edit its weight. Select an output to inspect its row.

1. Concatenated head outputs: x[token, :]

Head boundaries label where features came from. Concatenation preserves the numbers; the projection then mixes them.

2. PyTorch weight[out, in] · shape (6, 6)

A matrix row defines one output feature. Its six columns span all heads. PyTorch transposes this stored matrix for row-vector input multiplication.

3. Compute selected output

Bars show accumulated contributions per head. Negative weights can subtract; these are not attention probabilities.

4. Projected output · same width, new features

There are no head boundaries in this output. Each of its six coordinates can combine features from any head. Equal input/output size does not mean equal values.

Exact arithmetic and what training learns
For output j: y[j] = Σᵢ x[i] × weight[j, i] + bias[j]. Without bias, omit that last term. During training, backpropagation updates the weights and optional bias. During this animation they stay fixed unless you edit them.
The animation serializes the arithmetic to make it visible. PyTorch normally computes the full matrix operation using optimized kernels, not this visual loop.
