### C-20261023-01 · A Fix for Softmax and Cross-Entropy

- **Class:** B
- **Date discovered:** 2026-10-23
- **Date published:** 2026-10-22 (v1)
- **Source:** https://arxiv.org/abs/2610.31642 (verified resolves; v1, Thu 22 Oct 2026 17:54:56 UTC, cs.LG)
- **Organization/researchers:** Jonathan T. Barron, Dan Gnanapragasam, Michael Tschannen. Affiliation not stated on the abstract page; independently confirmed via web search that Barron is a Principal Research Scientist at Google DeepMind (multiple 2026 sources, e.g. a CVPR 2026 workshop-talk writeup and his own bio page), so this is credible Google DeepMind authorship even though the paper itself doesn't state it.
- **Category:** training (numerical correctness of the softmax/cross-entropy primitive itself — the mechanism underlying every LM loss and every distillation loss)
- **What changed:** The course teaches softmax and cross-entropy as foundational, from-scratch-implemented building blocks (module-01 lesson-03/04, module-02 lesson-03/04 "backprop through linear + softmax + cross-entropy by hand"). This paper claims standard softmax/log-softmax/cross-entropy implementations (as commonly written, presumably including the textbook/PyTorch-equivalent formulation the course teaches) have two distinct numerical bugs, not algorithmic design choices: "Softmax Collapse," where floating-point rounding can zero out the target logit's gradient when that logit already dominates, breaking the invariant that softmax gradients sum to zero; and "Softmax Cancellation," where the cross-entropy/distillation loss produces a nonzero gradient even when student and teacher logits are numerically identical (should be exactly zero).
- **Technical summary:** The authors propose corrected implementations of log-softmax, softmax, and cross-entropy that fix both bugs, and report (per the abstract) that the fix removes an instability they call the "Slingshot" phenomenon, speeds up grokking under weight decay, prevents accuracy collapse without weight decay, and reduces student-model drift away from the teacher during distillation. They further argue that post-memorization logit growth settles into an equilibrium set by weight decay vs. Adam's epsilon hyperparameter. No models/datasets/effect sizes were retrievable from the abstract page alone (full paper not fetched); no code repository is linked from the abstract page.
- **Why it might matter:** If correct and reproduced, this is not a new technique but a correctness fix to the single most foundational primitive the course teaches from scratch — directly bearing on module-01/02's softmax/cross-entropy lessons and on module-17's distillation lesson (17.4, on-policy distillation, which explicitly computes a teacher/student logit-difference loss of the kind "Softmax Cancellation" would affect). A credible Google DeepMind author naming a specific, previously-unnamed numerical bug in something this foundational is a stronger-than-usual signal for a single preprint.
- **Evidence of adoption:** None — one day old, no stated venue, no code release, no third-party replication yet. This is a claim, not yet independently checked (explicitly noted here per protocol).
- **Major organizations using it:** None identified yet; Barron's Google DeepMind affiliation is independently corroborated but the paper does not claim institutional backing or deployment.
- **Open-source implementation:** none found on the abstract page.
- **Paper:** https://arxiv.org/abs/2610.31642
- **Code:** none found
- **Relationship to existing course material:** Directly touches already-taught foundational material: `lessons/module-01/lesson-03.md`, `lessons/module-01/lesson-04.md`, `lessons/module-02/lesson-03.md` (softmax/cross-entropy from scratch), and `lessons/module-17/lesson-04.md` (on-policy distillation's teacher/student logit loss). Checked via `lookup "softmax cross entropy gradient bug"` and `lookup "softmax collapse cancellation"` — only the existing lesson content matched, confirming this specific numerical-bug claim is new, not a duplicate.
- **Potential course lesson:** If independently reproduced, a correction/addendum to the existing from-scratch softmax/cross-entropy implementation in module-01/02 (a numerically correct reference implementation plus a short "why naive softmax/cross-entropy can be wrong, not just imprecise" note), and a pointer from module-17.4's distillation lesson if the cancellation bug is confirmed to affect the teacher/student loss form taught there.
- **Confidence:** low-medium — credible single-author-team affiliation (Google DeepMind) and a claim about something foundational rather than a marginal technique, but one day old, no code, no independent reproduction, and the full technical detail (exact formulas, model/dataset specifics) was not retrievable from the abstract page alone.
- **Recommendation:** monitor closely; worth an early look even before full weekly maturity given it bears on already-taught from-scratch code, not a new topic — revisit as soon as code or a fuller writeup appears, and verify the claimed bugs against the course's own existing from-scratch softmax/cross-entropy implementation in `code/`.
